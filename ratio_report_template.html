SPY: long 1-year straddle + daily short 2x-mid / 1x-far ratio spread

⚠ UNCAPPED RISK — read before using this structure

Unlike the earlier iron-butterfly version, this daily short has no purchased wing. Loss accelerates from 2×/point once SPY passes the mid strike to 3×/point once it passes the far strike — there is no ceiling on the loss beyond that.
